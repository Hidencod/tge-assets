# Tiny Game Engine — free model library

Free 3D models for [Tiny Game Engine](https://github.com/Hidencod/TinyGameEngine), browsable from the editor
(Assets → **Free models**, or **+ Add → Free models library**). Served with GitHub Pages at
https://hidencod.github.io/tge-assets/.

1883 models in 19 packs, all by [Kenney](https://kenney.nl) under **CC0 1.0** (public domain):
free for personal and commercial games, no credit required.

## Layout

- `catalog.json`: packs and models (`file`, `thumb`, `size`)
- `packs/<pack>/<model>.glb`: self-contained GLB (textures embedded)
- `packs/<pack>/thumbs/<model>.webp`: 192×192 thumbnail

Generated by `tools/asset-library/build.mjs` and `thumbs.mjs` in the TinyGameEngine repo. Don't edit by hand.
